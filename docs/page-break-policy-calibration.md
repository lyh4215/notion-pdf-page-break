# PDF 페이지 분할 정책 보정 테스트

이 문서는 Notion PDF export가 페이지 하단에서 어떤 블록을 이전 페이지에 남기고, 어떤 블록을 다음 페이지로 넘기는지 확인하기 위한 보정 문서입니다.

테스트 방법:

1. 이 문서 전체를 새 Notion 페이지에 붙여넣습니다.
2. `[EQUATION: ...]` 마커 바로 아래에는 Notion의 수식 블록을 직접 추가합니다.
3. PDF export는 A4, scale 100%로 진행합니다.
4. 생성된 PDF를 공유해 주세요.

수식 입력값:

- `[EQUATION: SHORT]`: `E = mc^2`
- `[EQUATION: MEDIUM]`: `P(A \mid B)=\frac{P(A \cap B)}{P(B)}`
- `[EQUATION: TALL]`: `\begin{aligned} L(\theta)&=\prod_{i=1}^{n}p(x_i\mid\theta)\\ \log L(\theta)&=\sum_{i=1}^{n}\log p(x_i\mid\theta)\\ \hat{\theta}&=\arg\max_\theta \sum_{i=1}^{n}\log p(x_i\mid\theta) \end{aligned}`
