# Notion PDF soft boundary 보정 테스트

이 문서는 Notion PDF export가 페이지 하단 근처에서 새 블록을 이전 페이지에 남기는지, 다음 페이지로 넘기는지 확인하기 위한 전용 보정 문서입니다.

테스트 방법:

1. 이 문서 전체를 새 Notion 페이지에 붙여넣습니다.
2. PDF export는 A4, scale 100%로 진행합니다.
3. `[EQUATION: SHORT]` 바로 아래에는 Notion 수식 블록을 직접 추가합니다.
4. `[EQUATION: TALL]` 바로 아래에는 Notion 수식 블록을 직접 추가합니다.
5. 생성된 PDF와 프로그램 estimate txt를 공유해 주세요.

수식 입력값:

- `[EQUATION: SHORT]`: `E = mc^2`
- `[EQUATION: TALL]`: `\begin{array}{l} L(\theta)=\prod_{i=1}^{n}p(x_i\mid\theta) \\ \log L(\theta)=\sum_{i=1}^{n}\log p(x_i\mid\theta) \\ \hat{\theta}=\arg\max_{\theta}\sum_{i=1}^{n}\log p(x_i\mid\theta) \end{array}`

관찰 포인트:

- `[TARGET ...]` 블록이 이전 페이지 끝에 남는지, 다음 페이지 첫 블록으로 넘어가는지 확인합니다.
- target 바로 앞의 `[FILLER ...]` 블록이 페이지 끝에서 어디까지 들어갔는지도 같이 봅니다.
- 특히 페이지 하단에 남은 공간이 애매한 경우를 보기 위한 문서라, target marker가 많습니다.

## 6. 코드 block split policy

[FILLER CODE-A1] 코드 블록이 페이지 하단에 걸릴 때 중간에서 나뉘는지, 아니면 다음 페이지로 넘어가는지 확인하기 위한 문단입니다.

[FILLER CODE-A2] 코드 블록이 페이지 하단에 걸릴 때 중간에서 나뉘는지, 아니면 다음 페이지로 넘어가는지 확인하기 위한 문단입니다.

```js
const page = "soft-boundary-calibration";
const shortEquation = "E = mc^2";
const longEquation = "L(theta) = product(p(x_i | theta))";
function calculateBoundary(usedHeight, blockHeight, pageHeight) {
  const remaining = pageHeight - usedHeight;
  const overflow = blockHeight - remaining;
  return { remaining, overflow };
}
```
